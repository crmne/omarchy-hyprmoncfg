# hyprmoncfg panel 2.11.0

Manage workspaces from their own bar popup, with a picker that follows your monitor layout. Requires hyprmoncfg 1.24.0 or newer; [1.26.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.26.0) is recommended and enables the connected picker offer.

Install or update through Omarchy's plugin manager: [hyprmoncfg panel](https://github.com/crmne/omarchy-hyprmoncfg).

![The Workspaces canvas offering the optional picker with a preview of numbers grouped by monitor](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.11.0/design/releases/2.11.0-workspaces.png)

![The workspace-only popup with strategy, group size, monitor order and workspace assignments](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.11.0/design/releases/2.11.0-picker.png)

*Real QML interface with synthetic monitors, rendered on the GPU in an isolated display.*

## New

- **A picker that follows your monitors.** The Workspaces canvas previews the optional [hyprmoncfg Workspaces widget](https://github.com/crmne/omarchy-hyprmoncfg-workspaces/releases/tag/v0.1.0). Install it or use it in the bar through Omarchy's normal plugin flow. The offer disappears once enabled.
- **The Workspaces page, directly from the bar.** Right-click the picker for strategy, counts, order, assignments and the existing Apply/Save confirmation controls. The hyprmoncfg button opens the full display editor from its own icon, preserving drafts and previews.
- **One setup flow for both panels.** A missing or outdated daemon uses the same installation screen and service controls. The planner appears when the daemon is ready. The monitor icon retains Omarchy's native size, with a small theme-accent check.

## Fixed

- **Daemon disconnects no longer crash the shell through socket teardown.** Socket closure is deferred in the panel and preview guard to avoid re-entering Quickshell's socket handling. Reported and fixed by @Brams-s in [#43](https://github.com/crmne/omarchy-hyprmoncfg/pull/43).

## Known limitations

- The connected picker offer requires hyprmoncfg 1.26.0 and an applied workspace plan. Existing picker installations can still switch live workspaces with older daemons.
- Holding the workspace-count or group-size stepper changes it once. Type a number for larger changes.

## What's tested

All 234 Node tests and 42 QML tests pass, along with qmllint and plugin validation. Release captures use synthetic data. Socket recovery was checked with repeated peer closures; this is not a claim of full physical sleep/wake coverage.
