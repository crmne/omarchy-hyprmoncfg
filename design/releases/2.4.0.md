# hyprmoncfg panel 2.4.0

A redesigned panel: a tidier compact view, a cleaner full editor, and fewer surprises when you plug in a display. It needs [hyprmoncfg 1.19.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.19.0).

![Compact display panel](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.4.0/preview.png)

## A redesigned editor

- The full editor's tabs are now **1 Layout, 2 Workspaces, 3 Profiles**, same as the TUI. If your fingers know 2 and 3, heads up: they've swapped.
- Identify all, Keys, TUI, and Compact sit together in one slim header. Setup status and Create profile share a single footer with the compact panel, so there's no extra TUI card or repeated status line.
- Display cards and Identify show the connector, model with screen size, resolution and refresh rate, scale, position, and workspaces, all kept short: `3840x2160@144Hz`, `1.5x`, `32"`.
- All six hardware details are shown up front, next to a plain Identify button. No more "More details" toggle. Live brightness stays in the compact panel, separate from profile settings.
- Position has − / + steppers on either side of the value. Displays that are off or mirrored stay visible and selectable.

![Expanded layout editor](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.4.0/screenshots/layout.png)

## Profiles

- Right-click a profile, click its menu button, or use the keyboard to open its menu right next to it. Deleting asks first, in a dialog that matches your theme.
- Columns line up, and the redundant selection arrow is gone. **Post-apply command** has one name everywhere, can be edited, and comes last in the details.
- You can preview a saved profile without turning automatic selection off first. The preview countdown is now **30 seconds**.
- Once the backend confirms a save, the editor counts as clean, so it stops offering Preview & save for work you've already saved.
- The "Review marketplace verification" prompt that never went away is gone. Install, compatibility, and daemon-restart prompts still show up when they're actually needed.

![Saved profiles](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.4.0/screenshots/profiles.png)

## Refreshes that don't lose your work

Background refreshes keep your unsaved edits and whatever you're typing. A late reply can't overwrite a newer layout or preview, and when Hyprland is busy the panel keeps showing the last snapshot while it tries again.

Identify always starts from a fresh snapshot, lets clicks pass through, and cancels itself when displays change or a preview starts. It never applies a layout, and it won't cover a preview running in the TUI.

The workspace editor lets you pick **First per display** or **All assigned** persistence. The backend now uses Sequential for new plans and for single-display imports that could go either way, and keeps the workspace plans you've saved.

![Workspace planner](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.4.0/screenshots/workspaces.png)

## Upgrading

You'll need **hyprmoncfg 1.19.0 or newer**. Upgrade the backend, restart its service, then update the plugin:

```sh
systemctl --user restart hyprmoncfgd.service
omarchy plugin update crmne.hyprmoncfg
```

If an open shell still shows the old panel, close it and run `omarchy restart shell`.

## Good to know

The screenshots are the real panel rendered with made-up profiles and displays, not captures from real hardware. The panel and TUI now share the same names and workflows, but the TUI doesn't have its own Identify or a profile context menu yet. Layout reuse, shared preferences, and notification routing aren't part of this release. The [backend notes](https://github.com/crmne/hyprmoncfg/releases/tag/v1.19.0) list what's still missing for recovering from all-displays-off situations.
