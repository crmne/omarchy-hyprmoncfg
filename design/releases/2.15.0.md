# hyprmoncfg panel 2.15.0

Two more VRR modes, and no more frozen shell when the compact panel opens on a short screen. Requires hyprmoncfg 1.24.0 or newer; the new VRR modes need hyprmoncfg 1.29.0.

Install or update through Omarchy's plugin manager: [hyprmoncfg panel](https://github.com/crmne/omarchy-hyprmoncfg).

## New

- **Follow global and Fullscreen (games) for VRR.** The VRR selector lists them beside Off, On and Fullscreen, with the same names as the TUI. They appear only with a daemon that can save them, hyprmoncfg [1.29.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.29.0) or newer. Requested by @anthonyma94 in [crmne/hyprmoncfg#114](https://github.com/crmne/hyprmoncfg/issues/114).

## Fixed

- **Opening the compact panel on a short screen no longer freezes the shell.** When the panel only just failed to fit, the display stage and the scrollbar resized each other forever. Reported and fixed by @beyondDREADFUL in [#50](https://github.com/crmne/omarchy-hyprmoncfg/issues/50) and [#51](https://github.com/crmne/omarchy-hyprmoncfg/pull/51).

## What's tested

282 Node tests pass, along with the QML suites. The layout loop was reproduced with the real scrolling container in an offscreen QML test, where the old sizing logs a polish loop and the new one settles. The panel itself was not run at a clamped height, and the VRR selector was not captured or tried on real monitors.
