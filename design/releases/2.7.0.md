# hyprmoncfg panel 2.7.0

The panel gets Omarchy's Text size slider, and workspace numbers now glide between displays when their plan changes. It works with [hyprmoncfg 1.19.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.19.0) or newer; [1.22.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.22.0) is recommended.

![The compact panel at 12 px and at 16 px text, with the Text size slider under Brightness](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.7.0/design/releases/2.7.0-text-size.png)

*Synthetic displays, rendered offscreen.*

## New

- **Text size, as in Omarchy's own Display panel.** The compact view has the same slider under Brightness, with the same stops from 9 to 20 px. It changes text across the desktop, in the Omarchy shell, GTK apps and terminals, by running Omarchy's own `omarchy-display-text-size`. Like brightness, it is a desktop setting: it isn't saved in profiles and applies to every display. To make everything larger on one display, use Scale.
- **Workspaces glide to their new display.** When you switch between Sequential and Interleave, change the group size or reassign a workspace, each number moves from its old display to its new one instead of jumping, so you can see where it went. Numbers that stay on their display don't move.

![Four frames of workspace numbers travelling between three displays as the plan changes from Sequential to Interleave](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.7.0/design/releases/2.7.0-chip-travel-grid.png)

*The glide takes about a quarter of a second; these frames are slowed down.*

## Fixed

- **The compact view stays usable when it outgrows the screen.** With large text or many displays it used to cut off its bottom rows. Its header and the Profile actions now stay in place and the part between them scrolls.

## Known limitations

- **The glide is skipped** when more than 12 numbers would move, while you drag a display or the panel resizes, on display cards too small to show separate numbers, and when Hyprland animations are turned off.
- **Text size needs Omarchy's `omarchy-display-text-size`.** Without it the slider is hidden.
- **The Keep and Revert bar scrolls with the compact view** when the view is taller than the screen, and is brought into view when it appears.

## What's tested

Node tests (177), offscreen QML tests (21), checks that drive the real panel in an isolated host (58) and plugin validation pass. The images were rendered offscreen with sample data. Live use so far is limited to the maintainer's desktop, and scrolling the compact view with a mouse wheel or touchpad hasn't been tried.
